**4. TABLES**

Preview:

<table align="center">
  <tr>
    <td align="center"><b>About Me</b></td>
    <td align="center"><b>Details</b></td>
  </tr>
  <tr>
    <td>Name</td>
    <td>meowdoku</td>
  </tr>
  <tr>
    <td>Likes</td>
    <td>Cats, music, singing</td>
  </tr>
</table>

<sub> remove the space when creating a table </sub>

1. Add < table > to start the table.
2. Add < tr > to create a row.
3. Add < td > for each cell.
4. Add < /tr > to end the row.
5. Add < /table > to end the table.

> NOTE: You can always add images, texts, or anything in the table :3


Common Terms:

- img src - image address for the image
- width - size
- align - alignment of the text
